HTML Cell Preview

An Excel add-in for Windows and Mac. Select a cell containing HTML and see it rendered in a side pane, using a modern browser engine, with scripts and other active content removed.

Install on Windows

  1. Close Excel.
  2. Open PowerShell from the Start menu (no administrator rights needed).
  3. Paste the commands below and press Enter.
  4. Start Excel. The HTML Preview button appears on the Home tab.
$dir = "$env:LOCALAPPDATA\ExcelHtmlCellPreview"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
Invoke-WebRequest -UseBasicParsing "https://sylumer.github.io/excel-html-cell-preview/manifest.xml" -OutFile "$dir\manifest.xml"
$key = "HKCU:\Software\Microsoft\Office\16.0\WEF\Developer"
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name "fd002e3c-eb36-42cf-8c68-96dbc1c3fc8b" -Value "$dir\manifest.xml" -PropertyType String -Force | Out-Null
"Installed. Start Excel."

What this does: saves a copy of the add-in's manifest to your user profile and adds one entry under your own registry hive (HKEY_CURRENT_USER) telling Excel where it is. Nothing is installed system-wide.

Install on Mac

  1. Quit Excel.
  2. Open Terminal (Applications → Utilities).
  3. Paste the command below and press Return.
  4. Start Excel. The HTML Preview button appears on the Home tab.
d=~/Library/Containers/com.microsoft.Excel/Data/Documents/wef; mkdir -p "$d" && curl -fsSL https://sylumer.github.io/excel-html-cell-preview/manifest.xml -o "$d/excel-html-cell-preview.xml" && echo "Installed. Start Excel."

What this does: copies the add-in's manifest into Excel's own add-ins folder.

If the button does not appear

  • Go to Home → Add-ins (or Insert → My Add-ins on older versions) and choose HTML Cell Preview under Developer Add-ins. After the first time, the button stays on the ribbon.
  • Make sure Excel was fully closed when you ran the install, then restart it.
  • Your network must be able to reach sylumer.github.io and appsforoffice.microsoft.com.

Using it

  • Click HTML Preview on the Home tab to open the pane. Select any cell and the pane shows its HTML rendered. The pane follows your selection and updates when the cell changes. Formulas are fine: the pane shows the formula's result.
  • Images, fonts and media load from https:// addresses, so the remote server can see that the content was viewed.
  • Links do not open. Clicking one shows a banner with its address.

Safety

  • The HTML is cleaned with DOMPurify, which removes <script>, <iframe>, <object>, event handlers such as onclick, and javascript: links.
  • The cleaned HTML is then shown in a sandboxed frame with scripts, forms, pop-ups and navigation disabled, and a content security policy that blocks all network access except loading images, fonts and media.
  • The add-in only has permission to read the workbook. Cell contents never leave your computer.

Uninstall

Windows (PowerShell):

Remove-ItemProperty -Path "HKCU:\Software\Microsoft\Office\16.0\WEF\Developer" -Name "fd002e3c-eb36-42cf-8c68-96dbc1c3fc8b" -ErrorAction SilentlyContinue
Remove-Item "$env:LOCALAPPDATA\ExcelHtmlCellPreview" -Recurse -Force -ErrorAction SilentlyContinue
"Removed. Restart Excel."

Mac (Terminal):

rm -f ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/excel-html-cell-preview.xml && echo "Removed. Restart Excel."
